# 📚 Library Management System - Frontend

The frontend of the Library Management System built with HTML, CSS, and JavaScript. It communicates with the Spring Boot backend via REST APIs.

---

## 🚀 Features

- 🔐 User Login & Registration
- 🏠 Home dashboard for library overview
- 📖 Search books by title, author, or category
- 👤 User profile management
- 🛠️ Manager panel for admin operations

---

## 🛠️ Tech Stack

| Technology  | Usage                     |
|-------------|---------------------------|
| HTML        | Structure                 |
| CSS         | Styling                   |
| JavaScript  | Interactivity & API calls |

---

## 🖥️ How to Run

### 1. Clone the repository
```bash
git clone https://github.com/Darshan-11-create/LibraryManagement.git
cd LibraryManagement
```

### 2. Make sure the Backend is running
This frontend connects to the Spring Boot backend deployed on Render.

> 🔗 Backend Repo: [libraryManagementBackend](https://github.com/Darshan-11-create/libraryManagementBackend)

### 3. Open the app
Simply open `index.html` in your browser, or use the Live Server extension in VS Code for best results.
